# 🤖 Machine Learning & Time Series Analysis

This repository contains practical implementations, notebooks, and workflows for predictive modeling, cross-validation, hyperparameter tuning, and time series forecasting using **Scikit-Learn**, **XGBoost**, and **Pandas**.

It represents Phase 2 of my learning roadmap toward **Water Systems AI, Digital Twins, Decision Support Systems (DSS), and MLOps**.

---

## 📌 Topics & Modules Covered

### 1. Intro & Intermediate Machine Learning
- **Model Building:** Decision Trees and Random Forests implementation.
- **Model Validation:** Train/test split and Cross-Validation strategies to prevent overfitting.
- **Data Preprocessing:** Missing value imputation and categorical encoding (One-Hot & Ordinal Encoding).
- **Gradient Boosting:** Advanced tabular modeling with **XGBoost**.
- **Pipelines:** Streamlining data preprocessing and model evaluation workflows with Scikit-Learn Pipelines.

### 2. Time Series Analysis
- **Core Concepts:** Trend, seasonality, and cycles in temporal data.
- **Forecasting Models:** Linear regression as a time-series model and hybrid models combining linear regression with tree-based algorithms (XGBoost).
- **Time Series Features:** Lag features, rolling statistics, seasonal indicators, and Fourier transforms.
- **Evaluation & Validation:** Time-based splitting and evaluation strategies for non-stationary temporal datasets.
